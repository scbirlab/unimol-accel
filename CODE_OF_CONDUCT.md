# Code of conduct

We want this project to be welcoming to everyone. Be respectful, assume good faith, give and accept constructive
feedback graciously, and keep discussion focused on the work. Harassment, discrimination and personal attacks are
not tolerated.

Maintainers may edit, remove or reject contributions and may temporarily or permanently ban contributors who
violate these expectations. Report concerns privately to the maintainers via the contact on the GitHub profile of
the repository owner. This text is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
